# dsbx-sample

YouTube チャンネル「ずんだもんの実験道具箱」の Docker Sandboxes 回で使ったサンプルです。回ごとにディレクトリを分けています。

- [`no04/`](no04/) — Docker Sandboxes④: 檻の中を、いつものエディタで直すのだ（檻の中で動く1枚のアプリを、手元の VS Code とブラウザで直して確かめる）
- [`no05/`](no05/) — Docker Sandboxes⑤: 雲の檻で作らせて、閉じてもスマホで開く（cloud sandbox の Claude Code に頼んだ依頼文の全文と、公開から片付けまでの手順）

各ディレクトリの README に手順と実測の時点があります。動画と同じ中身を保つため、サンプル自体は改変しません。
