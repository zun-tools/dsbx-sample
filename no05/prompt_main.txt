~/shiori に、京都2泊3日の旅行のしおりサイトを作ってください。いま配信中の「準備中」の index.html を置き換えます。
- ページは6枚: 表紙（index.html）、1日目、2日目、3日目、持ち物チェックリスト、予算の目安。表紙から各ページへ行き来できるようにする
- 1日目〜3日目のページには、時刻・場所・ひとことメモの行程表（各日8行以上）と、雨の日の代わりの行き先を2つずつ書く
- 持ち物チェックリストは区分ごとに分ける。予算の目安は、日ごとの表と項目ごとの表の2つにする
- どのページにも <meta charset="utf-8"> を入れる
- HTML と CSS だけで作る。外部のライブラリ・CDN・Web フォント・画像は使わない。スマホの幅で読みやすくする
- 旅行者の名前・連絡先・予約番号は書かない。実在の人物名を入れない
- index.html は最後に置き換える（ほかのページを先に作る）
- 全ページを作ったら、http://localhost:8080 から6ページすべてを取得して 200 が返ること、ページ間のリンクに切れが無いことを確かめる
- サーバーは止めない・起動し直さない。~/shiori の外には何も置かない
- 全部できたら、最後に date -u '+%Y-%m-%dT%H:%M:%SZ' の出力を ~/shiori/done.txt に書き、できたページの一覧を報告する
